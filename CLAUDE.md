# Financial Analysis Project

## Overview

This is a financial data analysis tool for processing and analyzing financial datasets.

## Tech Stack

- **Python** with **pandas** for all data manipulation and analysis

## Project Structure

- `/data` — all data files (CSV, Excel, JSON, etc.) are stored here

## Development Notes

- Use pandas DataFrames as the primary data structure for financial data
- Keep raw data files in `/data` and avoid modifying them directly; write processed outputs to a separate subdirectory (e.g., `/data/processed`)
